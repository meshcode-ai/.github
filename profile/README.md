# meshcode.ai

**meshcode** is a native agentic development environment (ADE) for macOS and Windows — it drives the Claude Code or Codex CLI you already have, keeps the expensive model on judgment, and routes reading/search/boilerplate to cheap worker models. [Download at meshcode.ai](https://meshcode.ai).

## Open-source Agent Skills

73 knowledge-first [Agent Skills](https://agentskills.io/specification) for business work — 2KB each, MIT, works with meshcode, Claude Code, Codex, and Cursor.

| Repo | Skills |
|---|---|
| [skills](https://github.com/meshcode-ai/skills) | Hub — catalog, llms.txt, skill index |
| [skills-seo](https://github.com/meshcode-ai/skills-seo) | SEO/AEO — technical, AI search (GEO), E-E-A-T, schema, local, backlinks |
| [skills-marketing](https://github.com/meshcode-ai/skills-marketing) | Marketing — funnel analysis, CRO, growth, ads, lifecycle |
| [skills-copy](https://github.com/meshcode-ai/skills-copy) | Copy & content — landing copy, cold email, content strategy, brand voice |
| [skills-ops](https://github.com/meshcode-ai/skills-ops) | Operations — process mapping, SOP, capacity, vendors, compliance |
| [skills-biz](https://github.com/meshcode-ai/skills-biz) | Business planning — market sizing, pricing, PRD, unit economics |
| [skills-research](https://github.com/meshcode-ai/skills-research) | Research — deep research, literature review, surveys, patents |
| [skills-exec](https://github.com/meshcode-ai/skills-exec) | Executive & finance — advisors, board reports, cash flow, sales |

Install: download a repo zip → extract into your project's `.meshcode/skills/`.

- Catalog page: [meshcode.ai/skills](https://meshcode.ai/skills)
- AI-readable catalog: [llms.txt](https://meshcode-ai.github.io/skills/llms.txt)
- Skill index: [index.json](https://meshcode-ai.github.io/skills/index.json)
